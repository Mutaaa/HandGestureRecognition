# HandGestureRecognition

## 🚀 How to Start the Project

Follow these steps to set up and run the Hand Gesture Recognition app:

### 1. Install UV

```bash
brew install uv
```

### 2. Create a Virtual Environment

```bash
uv venv .venv
```

### 3. Install Dependencies

```bash
uv pip install -r requirements.txt
```

### 4. Run the Application

```bash
.venv/bin/python src/main.py
```

---

This will launch the hand gesture recognition app using your webcam.

If you encounter issues, make sure your camera is connected and accessible.
